int base,
_Bool c23,

Scan an integer as specified for strtol, strtoll, strtoul, and strtoull in C23 7.24.1.7, and set *endptr (if endptr is not null).

Parameters
nptrthe string to convert
endptrwhere to store the end of the subject sequence
basethe base, or 0 to determine the base from the prefix
c23whether to accept a "0b" or "0B" prefix for base 0 and 2, as C23 does
[out]negativewhether the subject sequence starts with '-'
[out]overflowwhether the magnitude exceeds ULLONG_MAX
Returns
the magnitude of the converted value, or ULLONG_MAX if overflow is set; 0 (with negative and overflow false) if no conversion could be performed
