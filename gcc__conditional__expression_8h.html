if_exprt lower_gcc_conditional_expression ( const side_effect_exprt & expr)
inline

Lower a single GCC conditional expression with omitted middle operand.

Rewrites the side effect a ? : b into the equivalent if-expression (a != 0) ? a : b. This drops the guarantee that a is evaluated only once, so it is only valid where a has no side effects – i.e. in constant contexts, or after side effects have already been removed (as in goto conversion).

Parameters
expra side_effect_exprt whose statement is ID_gcc_conditional_expression and which has exactly two operands
Returns
the equivalent if-expression, carrying expr's type and location

void lower_gcc_conditional_expressions ( exprt & expr)
inline

Recursively lower all GCC conditional expressions with omitted middle operand in expr.

Rewrites every side effect a ? : b into the if-expression (a != 0) ? a : b. Only valid in constant contexts, where the once-only evaluation of a is immaterial (there are no side effects), so that the simplifier can fold the result.
